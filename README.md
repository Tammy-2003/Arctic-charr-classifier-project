# Arctic-charr-classifier-project

Code associated with the MRes thesis:

**Development and evaluation of an acoustic classifier for detecting
Arctic charr spawning-related sounds**

Imperial College London, 2026.

## Overview

This repository contains the code used for data preparation,
model training, model evaluation, threshold analysis and subsequent
analyses presented in the thesis.

## Repository structure

- `code/` – analysis and modelling scripts
- `data` – a list of original data
- `example_clips/` – example acoustic clips

## Data availability

Original recording data is not included in this repository as they belong to 
UKCEH (UK Centre of Ecology and Hydrology). 

## Software

Python version: 3.10.20

Main packages:
- OpenSoundscape
- panns_inference
